# 3. The XML text set is not mirrored

Date: 2026-08-25

everyayah.com serves an `XML/` folder with the Arabic text and four translations split per surah. Its own `Arabic/00_warning.txt` says the files carry many mistakes and points readers to the Tanzil project; two translation files are empty; the Arabic is in a plain orthography rather than the Uthmani script. Mirroring it would put a known-bad copy of the Qur'an's text under this project's name, and a text that is wrong in one letter is not the Qur'an. Maqra therefore records that the folder exists (in the survey) and leaves it there. Qur'an text for any consumer of this archive should come from Tanzil or the Quran.com API, both of which publish verified text with a stated provenance. This decision is not open to a "with a warning label" compromise: the warning would be read less often than the file would be copied.
